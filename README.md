# DY-NoStop

抖音网页版在登录或未登录的时候播放一段时间会自己暂停，的确节约了电量（bushi），但这样很破坏观看或聆听体验，使用浏览器扩展注入脚本就能避免这个问题，使得其持续播放

自己按的暂停不受影响。点播放器、敲空格、切换视频、拖动进度条、断网缓冲、视频播完，这些都照常。

## 拦截与放行

脚本在页面每次调用 `video.pause()` 的时候判断一次。下面这些情况一律放行。

| 情况 | 判断依据 |
| --- | --- |
| 自己暂停 | 最近 1.5 秒内点过页面、按过键或者滚过滚轮 |
| 切换视频 | 最近 2.5 秒内地址变过 |
| 视频在视口外 | 元素不在当前可见区域，抖音本来就会停掉它 |
| 已有别的视频在播 | 页面上有另一个 video 正在播放 |
| 断网 | 浏览器报告离线 |
| 缓冲中 | `readyState` 不到 3 |
| 媒体出错 | 元素报错 |
| 播放结束 | 已经放到结尾 |
| 空元素 | 没有加载任何源 |

其余情况一律拦下来，视频继续播。

如果暂停仍然发生，还有一道看门狗，每 500 毫秒巡检一次，发现该播没播的就恢复。

## 一条硬要求

脚本靠改写 `HTMLMediaElement.prototype.pause` 生效，必须运行在页面自己的 JavaScript 上下文里。

所以头部的 `@grant` 必须是 `none`。一旦加上任何 `GM_*` 或者 `GM.` 开头的权限，管理器会把脚本放进沙箱，它改的是沙箱里那份原型，跟页面里管播放的那个没关系。这种情况下脚本会静默失效，控制台不报错，就是不管用。

装好之后，在抖音页面控制台跑一句就能确认钩子挂上没有。

```js
__dz.hookActive()
```

返回 `true` 说明正常。

## 使用前提

需要有一个脚本管理器，如篡改猴、六耳猴等。

## 安装

1. 先装一个用户脚本管理器。（Tampermonkey、Violentmonkey、ScriptCat 都能用。）
2. 将脚本内容放到脚本管理器里并启用
3. 刷新抖音页面。

## 可调参数

脚本顶部有几个阈值，环境不同可以自己改。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `KEEP_PLAYING_IN_BACKGROUND` | `true` | 切走标签页、最小化窗口之后是否继续播 |
| `USER_WIN` | 1500 | 用户操作之后多久内的暂停算用户按的 |
| `URL_WIN` | 2500 | 地址变化之后多久内的暂停算正常切换 |
| `RECENT_PLAY_WIN` | 60000 | 距上次播放超过这么久，看门狗不再介入 |

`USER_WIN` 调大，你自己的暂停更容易被误判成自动暂停，然后被拦回去。调小，抖音自己的暂停更容易漏网。

## 调试接口

在抖音页面控制台可以用下面这些。

| 接口 | 作用 |
| --- | --- |
| **`__dz.check()`** | 一键体检，看注入、钩子、拦截次数、放行明细 |
| `__dz.videos()` | 列出每个视频的可见性、画中画状态和尺寸 |
| `__dz.stats()` | 详细状态 |
| `__dz.count` | 累计拦截次数 |
| `__dz.log('BLOCK')` | 历史记录，可选 ALL、BLOCK、ALLOW、WATCHDOG |
| `__dz.dump('BLOCK')` | 打印历史，带调用栈 |
| `__dz.last()` | 最近一条记录 |
| `__dz.why()` | 试算当前这次暂停会被拦还是放行 |
| `__dz.hookActive()` | 钩子是否还生效 |
| `__dz.verbose(true)` | 连放行的暂停也打印 |
| `__dz.setBackground(false)` | 运行时关掉后台续播 |
| `__dz.clear()` | 清空记录和计数 |
| `__dz.help()` | 打印全部接口 |

拦截次数长时间为零是正常的。正常刷视频时绝大多数暂停都该放行，它不涨不代表脚本没干活。

## 已知限制

- 抖音改版之后可能失效。

## 兼容性

Chrome 和 Edge 系可以用。

Firefox 系需要先自测，用 `__dz.hookActive()` 确认钩子挂上了。Firefox 的扩展隔离比 Chrome 严，某些注入模式下脚本改不到页面原型。

## 隐私

脚本不发起任何网络请求。没有 fetch，没有 XMLHttpRequest，也没有 GM_xmlhttpRequest。所有判断都在本地完成，不收集、不上报任何数据。
